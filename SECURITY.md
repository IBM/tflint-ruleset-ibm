# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through one of these channels:

* [GitHub private vulnerability reporting](https://github.com/IBM/tflint-ruleset-ibm/security/advisories/new) for this repository
* [IBM PSIRT](https://www.ibm.com/trust/security-psirt)

To help us respond quickly, please include:

* Steps to reproduce or a proof of concept
* The plugin, TFLint and Terraform versions you used
* The relevant tool output, with any secrets removed

We aim to acknowledge reports within 3 business days and to keep you informed until the issue is resolved.

## Supported versions

Security fixes are released for the latest minor version only. Please upgrade to the latest release before reporting.

| Version | Supported |
| ------- | --------- |
| Latest minor release | Yes |
| Older releases | No |

## Verifying releases

Release checksums are signed and every artifact carries a GitHub build provenance attestation. See [Verifying releases](README.md#verifying-releases).
