# Changelog

## 0.1.0

Initial release of the IBM Cloud TFLint ruleset.

* Schema-validation rules for every managed resource and data source in the IBM Cloud Terraform provider
* One rule per writable argument (required values, enums, ranges, formats, nested blocks)
* OpenAPI overlay from published IBM Cloud API documents
* Extractor, generator, tests, docs, coverage audit, and goreleaser release pipeline
