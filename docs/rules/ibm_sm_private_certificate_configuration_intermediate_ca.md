# ibm_sm_private_certificate_configuration_intermediate_ca

Manages ibm_sm_private_certificate_configuration_intermediate_ca. A human-readable unique name to assign to your configuration.

This rule validates `ibm_sm_private_certificate_configuration_intermediate_ca` resources against the IBM Cloud provider schema and the published IBM Cloud API: required arguments, allowed values, numeric ranges, and format constraints.

OpenAPI schema: `PrivateCertificateConfigurationRootCAPrototype` (`secrets-manager-secrets-manager-v2`).

## Configuration

```hcl
rule "ibm_sm_private_certificate_configuration_intermediate_ca" {
  enabled = true
}
```
